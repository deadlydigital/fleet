Candidates

A tick produces a draft spec, not a build.

Each ticked candidate queues a draft-spec task: an agent with a read-only checkout writes a spec, a check verifies every path it names actually exists and that its work type has a contract, and then you review it. Only an approved spec becomes a code task.

Two hand-written specs contained wrong file paths. That class of error is machine-checkable, so it is checked rather than caught.
