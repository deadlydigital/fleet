{# The claim this page makes about itself, stated where it is checkable. #}
Every outcome column here is recomputed, not recorded.

decision_log holds what was decided and why. It has no outcome column at all — the task state, the cost, the attempts and the issue state below come from the decision_outcomes view, which reads the tasks, runs and issues each decision cited at the moment you load the page. There is no write route on this page and nothing here can be set by hand.

Recording one is fleet decision record --decision … --reason …. It stays in the shell on purpose: the reason is the part of this log that is worth keeping, and a box on a web page is where a reason turns into “yes”.
