Decide

Accepting re-runs the contract's verification against the tree this branch produces in {{ task.base_branch }} as it stands now, in a throwaway worktree, before anything is merged. The branch verifying on its own is a fact about the branch; a clean merge into broken code is what the base moving underneath actually costs. Expect it to take as long as the contract's checks do.

Accept

Merges {{ task.branch_name }} into {{ task.base_branch }} with --no-ff, pushes {{ task.base_branch }}, re-reads the remote to check the push landed, then records the verdict. It does not deploy.

Reject

Records the verdict. The branch is not touched, not deleted and not pushed.

These are the only two actions the console has. No rework, no re-run, no deploy, no task creation — those stay in the shell, where they are deliberate. Writes go as {{ writing_as }}; every page you have read was {{ running_as }}.
